# Contributing

Thanks for reading. This repo is a written case study: there is no code to run or extend, and the ByJoseM software itself is private.

- **Typos, broken links, unclear bits:** open an issue with the Correction template, or a small pull request.
- **Questions about how something was built or decided:** open an issue with the Question template.
- **Something that should not be public** (a personal detail, a real customer, a secret): never in an issue. Email diego@aiwithdiego.com, see [SECURITY.md](SECURITY.md).

Pull requests that add screenshots need demo data only. CI checks every pull request for secrets and for broken local links.

I answer issues within a few days.
