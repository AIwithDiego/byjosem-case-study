# Security policy

This repository contains documentation and demo-data screenshots only. It holds no source code, configuration or credentials.

If you find something here that should not be public, such as personal data, a real customer detail, an internal identifier or a secret, please email **diego@aiwithdiego.com**. Do not open a public issue or pull request for it.

The system this case study describes belongs to the client and is not in scope for testing. Please don't probe or scan it.
